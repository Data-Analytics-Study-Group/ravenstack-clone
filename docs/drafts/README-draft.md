# 📈 Ravenstack Customer 360
#### Data  Engineering, Analytics & Machine Learning On A Synthetic Dataset

> Status: Work in Progress (WIP)

## 📌 Overview

> A pre-launch analytics initiative built on the [SaaS Subscription & Churn Analytics Dataset](https://www.kaggle.com/datasets/rivalytics/saas-subscription-and-churn-analytics-dataset) — analysing churn risk, feature adoption, and support demand across the Ravenstack pilot customer base. This project focuses on data engineering, data analysis, and machine learning using data stored in a Neon PostgreSQL database.

The repository contains project code, documentation, notebooks, and supporting resources used throughout the project lifecycle.

## 🛠 Tech Stack
| Category | Tools |
|---|---|
| **Language** | PostgreSQL, Python |
| **Data manipulation** | pandas, NumPy |
| **Machine learning** | scikit-learn (Logistic Regression, MinMaxScaler, train/test split) |
| **Boosting** | XGBoost |
| **Statistical testing** | SciPy (Mann-Whitney U, linear regression) |
| **Time series forecasting** | Prophet (Facebook / Meta) |
| **Visualisation** | matplotlib, seaborn |
| **Model persistence** | joblib / pickle |
| **Documentation** | python-docx, Markdown |
| **Environment** | Jupyter Notebook, Neon |
| **Version control** | Git / GitHub |
