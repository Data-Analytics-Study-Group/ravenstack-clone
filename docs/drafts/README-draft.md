# The RAVENSTACK CUSTOMER 360 PROJECT
#### Data  Engineering, Analytics & Machine Learning On A Synthetic Dataset

> Status: Work in Progress (WIP)

## Overview

This project focuses on data engineering, data analysis, and machine learning using data stored in a Neon PostgreSQL database.

The repository contains project code, documentation, notebooks, and supporting resources used throughout the project lifecycle.

2. Populate the required environment variables
3. Install project dependencies
